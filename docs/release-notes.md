# ry马里奥之旅 v1.0.0

下载本页的 `ry马里奥之旅.exe`，双击即可游玩。单文件内嵌图片、头像、字体、音效和地图；不需要下载源码、外置素材或安装 Godot。

Windows x64，约 105 MiB，需要支持 OpenGL 3.3 的显卡驱动。

玩法：一个完整关卡，12 枚金币、3 只巡逻怪、两处坑、三段空中平台、可顶的幸运方块、变大蘑菇和终点旗帜。照片用于游戏图标和怪物头像，怪物有独立身体。

操作：A/D 或 ←/→ 移动；W/↑/空格跳跃，空中再按一次为二段跳；Esc 暂停；Enter 开始或重试；M 开关音效。

吃蘑菇后变大，碰怪一次变小；小角色碰怪或掉坑失败。下落踩怪可以消灭怪物。失败可重试，到旗帜即可通关，无需收集全部金币。

对应源码已通过 46 项功能检查，正式程序另行验证了只携带一个 EXE 的独立启动。README 附操作说明、截图和构建步骤。
